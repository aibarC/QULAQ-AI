# Пакет ручной разметки

Начните с [ANNOTATOR_GUIDE.md](ANNOTATOR_GUIDE.md). Для ИИ-помощника: [AI_HANDOFF.md](AI_HANDOFF.md).

В Git находятся инструкции, исходный текст чек-листа, безопасный шаблон `ANNOTATION_TEMPLATE.xlsx` с вымышленным `example-001` и генератор. Шаблон показывает структуру и содержит пустые оценки; он не заменяет полный приватный пакет.

Полный `ANNOTATION_PRIVATE.zip` передаётся партнёру отдельным приватным файлом. Внутри: `ANNOTATION.xlsx` (65 диалогов, 520 строк), `DIALOGUES.md`, 65 файлов `dialogs/`, обе инструкции, `CHECKLIST_SOURCE.txt` и `manifest.json`. Все оценки пустые, старые AI references не включены. Первые три диалога: `p1-ru-001`, `p1-kz-001`, `p1-en-001`.

Распаковывайте вне репозитория либо в `.local/annotation/`. Возвращайте заполненную копию XLSX приватным файлом. Реальные диалоги, цитаты и заполненные таблицы не добавляются в Git даже при приватном репозитории. Аудиоссылки и секреты в пакет не входят.

## Воспроизведение пакета для технического участника

Партнёру не нужно запускать генератор: готовый XLSX открывается в Excel или другом совместимом редакторе. Генератор подготовлен для повторного создания пакета текущего DEV (65 диалогов) или чистого вымышленного шаблона. Для иного набора сначала адаптируйте инструкции, числа и стартовые ID.

Генератор использует Node.js и `@oai/artifact-tool` из bundled runtime Codex (при подготовке — bundle 26.1026.10807). Получите пути через `load_workspace_dependencies`, используйте его Node и `node_modules`; не устанавливайте случайный одноимённый пакет. Для разрешения импорта можно создать игнорируемую ссылку `tools/annotation/node_modules` на каталог библиотек runtime. Если runtime недоступен, используйте готовый XLSX.

Из корня репозитория, после настройки runtime:

```sh
node tools/annotation/build_annotation.mjs .local/datasets/DEV.json .local/annotation/new-batch
```

Целевая папка должна быть новой: генератор откажется перезаписывать существующую разметку. Если вывод внутри репозитория, приватный пакет допускается только в `.local/`. Никаких сетевых запросов и вызовов модели генератор не делает.

Для безопасного вымышленного шаблона:

```sh
node tools/annotation/build_annotation.mjs --template .local/annotation/new-template
```

`ANNOTATION_PREVIEWS=1` включает PNG-проверки оформления. Эти изображения не включаются в приватный архив и Git. Номер `m1` соответствует первой исходной реплике, нумерация начинается заново в каждом диалоге. Исходный порядок внутри разговора сохраняется; три пробных разговора выведены первыми для удобства.

`manifest.json` содержит SHA256 исходного JSON, число диалогов/реплик и версию чек-листа. Он не назначает train/validation/test. Перед выбором независимого теста требуется отдельно проверить историю использования разговоров и близкие шаблоны.
