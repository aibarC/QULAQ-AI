## Изменяемый чек-лист

Редактор позволяет изменять правила через интерфейс. Backend сохраняет снимок чек-листа и передаёт изменённые правила в динамический промпт. Технические тесты проверяют применение конфигурации, полноту результата, пересчёт и сохранность истории. Указанная выше метрика относится только к стандартным восьми критериям.

Общий пример улучшенного разговора запрашивается отдельной кнопкой после сохранения оценки. Этот дополнительный запрос не переписывает исходные оценки; его качество не измеряется указанной метрикой.
