## Повторная офлайн-конвертация сохранённых ответов

Из backend (Node24+, зависимости установлены):

```sh
node --import tsx scripts/export-saved-submission.ts \
  --dataset=/private/path/DEV.json \
  --records=/private/path/final65-c6c7/records.json \
  --responses=/private/path/final65-c6c7/results.json \
  --output=/private/path/new-results.json \
  '--team=Amazing Guys' --group=DEV --count=65 --checklist=current
```

Скрипт принимает criteria-only сохранённые ответы; невалидные попытки включает как status=error. Для текущего прогона обязательно --checklist=current; исторический снимок доступен как --checklist=legacy-c6. Скрипт проверяет совпадение транскриптов и баллов, не загружает `.env`, не импортирует провайдер и не использует сеть. Уже существующий выходной файл не перезаписывает. Для текущего Workspace, включая ошибки обработки, используйте `POST /api/exports/submission` или кнопку официального экспорта в UI.

В приложении собственные пользовательские правила/веса остаются доступными. Но официальный экспорт требует сохранённую оценку по стандартным восьми правилам: он не переименовывает произвольный новый критерий в один из официальных и не подставляет старую удачную оценку вместо последней ошибки.
